# 디자인 시스템 — 일일보고 · 주간보고

실제 값은 `frontend/src/styles/tokens.css` 한 곳에만 있다. 이 문서는 **언제 무엇을 쓰는지**를 정한다.
참고: `docs/design-reference.md`(Linear · Notion 크롬 규칙), 사내 문서 도구의 종이 · 먹 · 도장 감각.

## 1. 현재 UI 분석 — "AI가 만든 느낌"이 나던 요소

| # | 패턴 | 어디서 | 왜 AI처럼 보이나 | 바꾼 것 |
|---|---|---|---|---|
| 1 | 점 + 글자 + 알약 배경의 상태 배지 | `.state-chip`, `.status-chip`, 사이드바 "오늘 미제출" | 생성형 UI가 거의 기본값으로 내놓는 모양 | 배경 없는 **아이콘 + 굵은 글자**, 중립 상태는 **테두리 라벨** |
| 2 | 흔한 SaaS 파랑 `#0075de` | 버튼 · 링크 · 선택 | 서비스 성격과 무관한 기본 파랑 | 보고서 종이에 맞춘 **세이지 포레스트 `#4d6a39`** + 크림 배경 |
| 3 | 의미 없는 파스텔 면 | 분류 태그(완료 · 진행 · 이슈…), 미제출 이름 칩 | 색 면이 너무 많아 무엇이 중요한지 흐려짐 | 분류는 **테두리 라벨**. 면은 '이슈' 하나만(막힌 일은 눈에 띄어야 함) |
| 4 | 어디에나 알약(pill) | 메뉴 · 세그먼트 · 주 이동 · 칩 | 모서리가 전부 둥글면 장난감처럼 보임 | 원형은 **아바타만**. 컨트롤 6px, 카드 8px, 대화상자 12px |
| 5 | 모든 걸 카드로 감쌈 | 내 현황 '오늘' 카드, 작성 옆 안내 2장, 주간 상세 카드 속 카드 | 구조가 아니라 상자가 보임 | 오늘 상태는 **페이지 제목 자체**, 옆 안내는 **가는 선 아래 글**, 카드 속 트레이 제거 |
| 6 | 같은 타일 반복 그리드 | 이번 주 5칸 타일, 주간 날짜 5칸 타일 | 똑같은 상자 5개 | **한 틀 안의 달력 줄**(세로 헤어라인으로 나눔) |
| 7 | 번호 원 ①②③ 단계 표시 | 작성 옆 "세 단계" | 튜토리얼 템플릿 느낌 | "지금 · 다음 · 마지막" 말머리 텍스트 |
| 8 | 점선 상자 버튼 | "공지 추가", "프로젝트 추가", 빈 상태 | 와이어프레임처럼 보임 | 조용한 **+ 텍스트 액션**, 빈 상태는 위아래 가는 선 |
| 9 | Inter + Pretendard 조합 | 전체 | 생성형 페이지의 기본 폰트 | **Pretendard Variable** 하나. 숫자는 tabular |

이모지 아이콘, 그라디언트, 글래스모피즘, 왼쪽 강조 보더 박스는 코드에 없음을 확인했다(재발 금지 항목으로 남긴다).

## 2. 방향

**"사내 보고서 종이 위의 먹과 도장."**
크림 종이 배경, 먹색 글자, 결정 버튼 하나만 세이지 포레스트. 빠진 것(미제출 · 빠진 요일)은 테라코타.
화려함 대신 **밀도와 정렬**로 전문성을 보인다 — 목록은 줄, 달력은 한 틀, 상태는 글자.

## 4. 타이포그래피

한 서체: Pretendard Variable. 역할 토큰은 `font` 한 줄로 쓴다(`font: var(--type-heading)`).

| 역할 | 토큰 · 클래스 | 크기 / 굵기 | 예 |
|---|---|---|---|
| Title | `--type-title` · `.t-title` | 24 / 700 | "오늘 일일보고를 아직 쓰지 않았어요", "9.28 ~ 10.2" |
| Heading | `--type-heading` · `.t-heading` | 16 / 600 | 섹션 제목, 목록 머리(14로 줄여 씀) |
| Body | `--type-body` · `.t-body` | 14 / 400 | 목록 줄, 보고 본문 |
| Description | `--type-desc` · `.t-desc` | 13 / 400 · muted | 제목 아래 한 줄 설명 |
| Caption | `--type-caption` · `.t-caption` | 12 / 500 · muted | 날짜 머리, 필드 이름, 칸 제목 |

모바일에서 Title은 20.

## 5. 간격

4px 격자(`--space-1…8`) 위에 역할 세 개.

| 역할 | 토큰 | 값 | 쓰는 곳 |
|---|---|---|---|
| 작은 간격 | `--gap-tight` | 8 | 버튼 묶음, 태그 사이 |
| 기본 간격 | `--gap` | 16 | 관련 블록 사이, 카드 안 |
| 섹션 간격 | `--gap-section` | 32 | 페이지의 큰 덩어리 사이 |

## 6. 컴포넌트

**Button** (`.btn`) — 높이 36 / 작게 32 / 터치 44, 모서리 6.
`.btn-primary`는 화면에 하나. 나머지는 흰 면 + 헤어라인. 삭제는 글자만 빨간 `.btn-danger` 또는 휴지통 아이콘(`.row-icon-btn`), 되돌릴 수 없는 확인만 `.btn-danger-solid`.

**Card** (`.card`) — 모서리 8, 헤어라인, 그림자 없음.
카드는 "한 번에 편집하는 단위"(프로젝트 하나, 공지 묶음)에만. 안내 · 상태 · 요약은 카드로 감싸지 않는다. 카드 안에 카드 · 트레이 금지.

**List** (`.group` + `.row`) — 흰 면 하나 안에서 줄을 헤어라인으로 나눔. 아바타가 있으면 선이 글자 시작점에서 시작.

**Badge** — 세 가지만.
- 상태 `.state-chip.is-{success|warning|danger|info}`: 배경 없는 아이콘(체크 · 연필 · 느낌표 · 채운 원) + 굵은 글자.
- 중립 `.state-chip.is-plain`, 기본 `.status-chip`: 테두리 라벨(모서리 3).
- 분류 `.cat-tag.is-{done|progress|issue|request|next}`: 테두리 라벨. '이슈'만 면을 채우고 '다음'은 점선.

**Input** (`.input`, `.textarea`) — 흰 면 + 헤어라인, 포커스는 세이지 링. 라벨은 Caption.

**Modal** (`.app-dialog`) — 모서리 12, 떠 있는 유일한 그림자(`--shadow-2`). 되돌릴 수 없는 작업은 빨간 확인 버튼.

**Navigation** — 사이드바는 바탕보다 어둡고, 선택된 메뉴만 흰 면 + 얕은 그림자. 알림은 빨간 글자(펼침) / 테두리 있는 점(접힘). 모바일 하단 탭은 선택 시 색만 바뀌고 배경 상자는 없다.

**Segmented** (`.seg`) — 2~4개 선택. 바깥 8, 안쪽 6.

## 7. 하지 않는 것

- 이모지를 아이콘으로 쓰기 (아이콘은 `lucide-vue-next`, stroke 2, 14–20px, 글자색 따라감)
- 그라디언트, 블러 유리 효과, 보라 · 네온 계열
- 왼쪽 강조 보더가 있는 설명 박스
- 알약 배경 + 점 상태 배지
- 같은 모양 타일을 줄 세운 그리드
- 점선 상자 버튼
