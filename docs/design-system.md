# 디자인 시스템 — 일일보고 · 주간보고

실제 값은 `frontend/src/styles/tokens.css` 한 곳에만 있다. 이 문서는 **언제 무엇을 쓰는지**를 정한다.
참고: `docs/design-reference.md`(Linear · Notion 크롬 규칙).

---

## 1. 현재 UI 분석 — "AI가 만든 느낌"이 나던 요소

| # | 패턴 | 어디서 | 왜 AI처럼 보이나 | 바꾼 것 |
|---|---|---|---|---|
| 1 | 점 + 글자 + 알약 배경의 상태 배지 | `.state-chip`, `.status-chip`, 사이드바 "오늘 미제출" | 생성형 UI가 거의 기본값으로 내놓는 모양 | 배경 없는 **아이콘 + 굵은 글자**, 중립 상태는 **테두리 라벨** |
| 2 | 의미 없는 파스텔 면 | 분류 태그(완료 · 진행 · 이슈…), 미제출 이름 칩 | 색 면이 너무 많아 무엇이 중요한지 흐려짐 | 분류는 **테두리 라벨**. 면은 '이슈' 하나만(막힌 일은 눈에 띄어야 함) |
| 3 | 어디에나 알약(pill) | 메뉴 · 세그먼트 · 주 이동 · 칩 | 모서리가 전부 둥글면 장난감처럼 보임 | 원형은 **아바타만**. 컨트롤 `--radius-sm`, 카드 `--radius`, 대화상자 `--radius-lg` |
| 4 | 모든 걸 카드로 감쌈 | 내 현황 '오늘' 카드, 작성 옆 안내 2장, 주간 상세 카드 속 카드 | 구조가 아니라 상자가 보임 | 오늘 상태는 **페이지 제목 자체**, 옆 안내는 **가는 선 아래 글**, 카드 속 트레이 제거 |
| 5 | 같은 타일 반복 그리드 | 이번 주 5칸 타일, 주간 날짜 5칸 타일 | 똑같은 상자 5개 | **한 틀 안의 달력 줄**(세로 헤어라인으로 나눔) |
| 6 | 번호 원 ①②③ 단계 표시 | 작성 옆 "세 단계" | 튜토리얼 템플릿 느낌 | "지금 · 다음 · 마지막" 말머리 텍스트 |
| 7 | 점선 상자 버튼 | "공지 추가", "프로젝트 추가", 빈 상태 | 와이어프레임처럼 보임 | 조용한 **+ 텍스트 액션**, 빈 상태는 위아래 가는 선 |

이모지 아이콘, 그라디언트, 글래스모피즘, 왼쪽 강조 보더 박스는 코드에 없음을 확인했다(재발 금지 항목으로 남긴다).

## 2. 방향

**색은 `tokens.css`에 정해 둔 팔레트를 그대로 쓴다.** 따뜻한 종이색 바탕, 먹색 글자, 파란 강조색 하나.
AI 느낌은 색이 아니라 **모양**(알약 배지, 상자 남발, 같은 타일 반복)에서 나왔으므로 모양을 고친다.
화려함 대신 **밀도와 정렬**로 전문성을 보인다. 목록은 줄로, 달력은 한 틀로, 상태는 글자로 보여 준다.

## 3. 컬러 토큰

값은 `tokens.css` 그대로다. 아래는 역할만 정한다. 새 색은 만들지 않는다.

| 역할 | 토큰 | 값 | 쓰는 곳 |
|---|---|---|---|
| Primary | `--primary` (= `--accent`) | `#0075de` | 화면마다 하나뿐인 주 버튼, 링크, 선택, 포커스 |
| Primary hover | `--primary-hover` (= `--accent-hover`) | `#005bab` | |
| Primary soft | `--accent-soft` | `#e8f1fc` | 선택된 줄, 오늘 칸 배경 |
| Attention | `--attention` (= `--danger-fg`) | `#b3261e` | 미제출, 빠진 날, 삭제 |
| Background | `--bg` / `--sidebar-bg` | `#f6f5f4` | 페이지 바탕 |
| Surface | `--surface` | `#ffffff` | 목록, 입력, 대화상자 |
| Text | `--text-strong` / `--text` / `--text-muted` | `#1c1b18` / `#37352f` / `#6f6e69` | 제목 / 본문 / 설명 |
| Line | `--border` / `--border-strong` | `#e7e5e2` / `#d3cfc9` | 헤어라인 / 테두리 라벨 |

의미 색은 글자색 기준으로 쓰고, 면은 거의 칠하지 않는다.

| 의미 | fg | 쓰는 곳 |
|---|---|---|
| success | `#1a7f37` | 저장됨, 제출, 완료 |
| warning | `#9a6700` | 초안, 이슈 |
| danger | `#b3261e` | 미제출, 빠짐, 삭제 |
| info | `#0b5cab` | 진행 중, 로그인 중, 재추출 중 |
| project-4 | `#5c5470` | 협조 요청 |

## 4. 타이포그래피

서체는 `tokens.css`의 `--sans`를 그대로 쓴다. 역할 토큰은 `font` 한 줄로 쓴다(`font: var(--type-heading)`).

| 역할 | 토큰 · 클래스 | 크기 / 굵기 | 예 |
|---|---|---|---|
| Title | `--type-title` · `.t-title` | 24 / 700 | "오늘 일일보고를 아직 쓰지 않았어요", "9.28 ~ 10.2" |
| Heading | `--type-heading` · `.t-heading` | 16 / 600 | 섹션 제목, 목록 머리(14로 줄여 씀) |
| Body | `--type-body` · `.t-body` | 14 / 400 | 목록 줄, 보고 본문 |
| Description | `--type-desc` · `.t-desc` | 13 / 400 · muted | 제목 아래 한 줄 설명 |
| Caption | `--type-caption` · `.t-caption` | 12 / 500 · muted | 날짜 머리, 필드 이름, 칸 제목 |

모바일에서 Title은 20.

## 5. 간격

4px 격자(`--space-1…8`) 위에 역할 세 개.

| 역할 | 토큰 | 값 | 쓰는 곳 |
|---|---|---|---|
| 작은 간격 | `--gap-tight` | 8 | 버튼 묶음, 태그 사이 |
| 기본 간격 | `--gap` | 16 | 관련 블록 사이, 카드 안 |
| 섹션 간격 | `--gap-section` | 32 | 페이지의 큰 덩어리 사이 |

## 6. 컴포넌트

**Button** (`.btn`) — 높이 36 / 작게 32 / 터치 44, 모서리 `--radius-sm`.
`.btn-primary`는 화면에 하나. 나머지는 흰 면 + 헤어라인. 삭제는 글자만 빨간 `.btn-danger` 또는 휴지통 아이콘(`.row-icon-btn`), 되돌릴 수 없는 확인만 `.btn-danger-solid`.

**Card** (`.card`) — 모서리 `--radius`, 헤어라인, 그림자 없음.
카드는 "한 번에 편집하는 단위"(프로젝트 하나, 공지 묶음)에만. 안내 · 상태 · 요약은 카드로 감싸지 않는다. 카드 안에 카드 · 트레이 금지.

**List** (`.group` + `.row`) — 흰 면 하나 안에서 줄을 헤어라인으로 나눔. 아바타가 있으면 선이 글자 시작점에서 시작.

**Badge** — 세 가지만.
- 상태 `.state-chip.is-{success|warning|danger|info}`: 배경 없는 아이콘(체크 · 연필 · 느낌표 · 채운 원) + 굵은 글자.
- 중립 `.state-chip.is-plain`, 기본 `.status-chip`: 테두리 라벨(모서리 `--radius-xs`).
- 분류 `.cat-tag.is-{done|progress|issue|request|next}`: 테두리 라벨. '이슈'만 면을 채우고 '다음'은 점선.

**Input** (`.input`, `.textarea`) — 흰 면 + 헤어라인, 포커스는 강조색 링. 라벨은 Caption.

**Modal** (`.app-dialog`) — 모서리 `--radius-lg`, 떠 있는 유일한 그림자(`--shadow-2`). 되돌릴 수 없는 작업은 빨간 확인 버튼.

**Navigation** — 사이드바는 바탕보다 어둡고, 선택된 메뉴만 흰 면 + 얕은 그림자. 알림은 빨간 글자(펼침) / 테두리 있는 점(접힘). 모바일 하단 탭은 선택 시 색만 바뀌고 배경 상자는 없다.

**Segmented** (`.seg`) — 2~4개 선택. 바깥 `--radius`, 안쪽 `--radius-sm`.

## 7. 하지 않는 것

- 이모지를 아이콘으로 쓰기 (아이콘은 `lucide-vue-next`, stroke 2, 14–20px, 글자색 따라감)
- 그라디언트, 블러 유리 효과, 보라 · 네온 계열
- 왼쪽 강조 보더가 있는 설명 박스
- 알약 배경 + 점 상태 배지
- 같은 모양 타일을 줄 세운 그리드
- 점선 상자 버튼
