## 1. 요구사항

- **입력**: 자유 형식 일일보고 원문 (개조식, 줄글, 메신저체, 표, 한 줄, 영문 혼합 등)
- **출력**: `backend/model_asset/json_Schema.json` 스키마를 준수하는 JSON
  - 프로젝트명 + 완료 업무 / 진행 중 업무 / 이슈 / 협조 요청 / 다음 계획
  - 이슈는 남은 문제만 문자열로. 해결된 문제는 완료 업무에만 넣음
- **환경**: 외부 API 호출 불가
- **제약**:
  - Q4 계열 양자화 GGUF만 로드
  - 추론(reasoning)은 medium (`reasoning_effort: "medium"`)
  - 응답 지연은 보고 1건당 수 초를 목표 (상한 10분)

## 4. 채택 판단

### 4.1 최종 채택: **Qwen3.8 27B** (`UD-Q4_K_XL`, 추론 medium)

- 운영 식별자: `unsloth/Qwen3.8-27B-GGUF:UD-Q4_K_XL`
- 같은 프롬프트·스키마에서 micro F1 1위, 지연도 가장 짧음
- 프로젝트 소속이 세 모델 중 가장 높고, JSON·스키마 100%
- JSON 스키마 출력을 전제로 thinking **medium**

### 4.2 제외 사유

| 모델 | 제외 사유 |
| --- | --- |
| **Gemma 4 31B-it** | micro F1 89.3%로 0.1%p 차. 평균 5.33s로 더 느림 |
| **Muse Glimmer-30B** | JSON 96.9%(1건 실패), F1 85.0%. 평균 7.98s로 가장 느림 |

### 4.3 운영 조건

- **로드**: `unsloth run --model unsloth/Qwen3.8-27B-GGUF:UD-Q4_K_XL --reasoning medium -c 32768 -p 8888`
- **추론**: 백엔드는 요청마다 `reasoning_effort: "medium"`을 명시적으로 전송.
  필드를 생략하면 Qwen3.8 27B가 기본적으로 추론을 켜므로 **생략 금지**
- **온프레미스**: Unsloth Desktop 로컬 API(`http://127.0.0.1:8888/v1`)
